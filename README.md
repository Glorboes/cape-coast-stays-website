# Cape Coast Stays

Responsive static redesign. Serve `dist/` with an HTTP server. No build step or dependencies.

## Content and assets
- Company copy, contact details, team biographies, real guest review excerpts and property catalogue sourced from https://capecoaststays.com on 7 October 2026.
- Photography downloaded from the company's existing website; original property-to-image mappings retained.
- Coastal video: Taryn Elliott, Pexels, https://www.pexels.com/video/drone-footage-of-a-beach-with-view-of-a-mountain-3326782/ (existing licensed footage from the Seajax project). New composition and brand styling; no Seajax property photography used.
- Colours drawn from the existing Cape Coast Stays navy/gold brand artwork, retained in assets/brand-artwork.png.
- Original booking listings and owner login remain the destinations for transactional actions. No simulated availability, rates, reservations or form submissions.

## Features
Responsive navigation, searchable 8-property catalogue, featured/Langebaan filters, property detail dialogs, email enquiries, phone links, guest review carousel, team biographies, controllable muted hero video and reduced-motion support.

Catalogue updated with the seven supplied Airbnb links on 7 October 2026; 203 La Cabina retained. Langebaan is an enquiry option pending property details.
